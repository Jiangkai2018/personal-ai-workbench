# 个人 AI 工作台 · 使用手册

> 把 **想法 → 机会 → 目标 → 任务 → 每日执行 → 复盘 → 沉淀** 的闭环跑起来。
> 无数据库、无注册：数据是本地 Markdown 文件，你是自己数据的唯一所有者。

---

## 1. 系统简介

「个人 AI 工作台」是一个本地优先的个人成长闭环系统。它解决的问题是：**想法很多、承诺很少、执行无从追踪**。

系统用一条主线串起所有模块：

```
想法（不判断好坏，先记下来）
  ↓ 一键转正（自动 AI 初评）
机会（5 维速评：值不值得做）
  ↓ 一键转正
目标（承诺投入的方向 + 里程碑 + 进度）
  ↓ 拆解
任务（今天/本周/未来 三档排期）
  ↓ 勾选完成
复盘（每晚汇总，自动更新目标进度）
  ↓ 反哺
目标进度可视化，形成第二天的执行依据
```

两条设计原则贯穿始终：

- **AI 只建议，不做决定**：AI 初评只填充分数，转正等承诺动作始终由你亲手点击（ADR-0003）。
- **一切皆文件**：每个想法、目标、任务都是一个带 YAML frontmatter 的 `.md` 文件，存在 `data/` 目录，可用 git 版本化兜底。

## 2. 快速开始

### 2.1 环境要求

- Node.js ≥ 22
- npm（随 Node 安装）

### 2.2 安装与启动

```bash
# 在仓库根目录执行（npm workspace 会一次装好 server / web / e2e）
npm install

# 一键启动后端(3000) + 前端(5173)
npm run dev
```

启动后浏览器访问 **http://localhost:5173**（前端会把 `/api` 代理到后端 3000 端口）。

### 2.3 创建账号（无自助注册）

系统不开放注册，用管理端 CLI 建号：

```bash
npm run add-user -w server -- --username jk --password 你的密码 --name 江凯 --family
```

| 参数 | 说明 |
| --- | --- |
| `--username` | 登录名（必填） |
| `--password` | 密码（必填） |
| `--name` | 显示名，默认同 username |
| `--family` | 标记为家庭成员（可参与家庭互证找回密码） |

账号已存在时会更新该账号（可用来改密码）。

### 2.4 生产构建

```bash
npm run build        # 构建 server + web
npm run start -w server   # 运行后端（web 构建产物在 web/dist，可挂任意静态服务）
```

## 3. 登录与会话

- 登录使用 用户名 + 密码；会话是 **JWT httpOnly Cookie，有效期 7 天**，期间刷新不掉线。
- **忘记密码 → 家庭互证找回**：登录页点「忘记密码？家人互证找回」，输入要重置的账号 + 新密码 + **另一位家人的账号密码**，验证通过即重置。
- 双方都忘记密码时，用 CLI 兜底：

```bash
npm run reset-password -w server -- --username jk --password 新密码
```

- 点顶栏右侧「退出」立即登出。

## 4. 界面导览

界面为「纸墨」风格：暖纸底、墨色字、朱砂点睛，手机/平板/桌面自适应。

- **顶栏**：左侧朱砂印章 + 标题；中间「个人 / 家庭」范围切换；右侧当前用户名 + 退出。
- **导航**：
  - 手机/平板：底部悬浮 Dock，六个入口带图标；
  - 桌面（≥1024px）：Dock 变为内容列右侧的竖排导航轨；内容列宽随屏幕比例展宽（2K 屏约 62% 屏宽）。
- **今日** 页首的捕获框是全局快捷入口：**3 秒记一个想法，不做任何判断**。

## 5. 各页面用法

### 5.1 今日（首页）

一天的起点和终点都在这页。

1. **快捷捕获**：顶部输入框回车即记一条想法（默认"成长"轨道）。想到什么记什么，好坏留给以后判断。
2. **今日要做的**：列出今天排期的任务；底部「+ 今天要做的」可快速加任务并挂靠活跃目标（或不挂目标 = 维护类琐事）。
3. **勾选完成**：点任务前的圆圈即完成（再点撤销）。
4. **开始复盘**：晚间点一次，生成当日复盘并自动更新目标进度（详见 5.6）。
5. **今日完成**：完成清单 + 完成率进度条。

### 5.2 想法（想法收件箱）

- 所有捕获的想法按时间倒序排列，标签显示 范围（个人/家庭）和 轨道（成长/维护）。
- **轨道含义**：`成长` = 指向目标、有复利的事；`维护` = 生活运维类琐事。
- **转正**：点「转正」一键升级为机会（无需确认环节），服务端**自动 AI 初评**；已转正的想法标注「已转正」。
- **编辑**：点「编辑」可修改正文与轨道（成长/维护）。
- **删除**：点「删除」并确认后从收件箱移除；**已转正**（被机会引用）的想法不能删，避免数据断链。

### 5.3 机会（5 维速评）

用五个维度给一个外部可能性打分，每维 **0–20 分**，总分 **0–100**：

| 维度 | 问的问题 |
| --- | --- |
| 价值度 | 天花板 + 复利：这事值多少钱、能不能积累？ |
| 可行度 | 现有技能/资源够得着吗？ |
| 时间窗 | 窗口期多长、东风到了没有？ |
| 匹配度 | 和我的优势/当前目标一致吗？ |
| 风险度 | 下行风险多大？（反向计分：分高 = 风险低） |

**分档规则（自动）**：

| 总分 | 状态 | 含义 |
| --- | --- | --- |
| ≥ 80 | 转正候选 | 值得承诺，可转正为目标 |
| 60–79 | 观察池 | 继续观察，等待条件变化 |
| < 60 | 归档 | 暂不投入 |

- **AI 初评（推荐起点）**：不自己从零打分 ——
  - 新建时：填完标题点「**AI 预评**」，5 个滑块自动填入建议分，拖动微调或直接创建；
  - 想法转正：转正瞬间服务端**自动 AI 初评**，打开机会页即可看到分数；
  - 已有机会：点「**AI 初评 / AI 重评**」随时（重）打分。
- **领域分析（深度报告）**：点「领域分析」发起异步深度分析（约 1–3 分钟）：
  - 三段式报告：**赛道与市场 → 同行格局（真实账号与数据画像）→ 切入策略与结论**；
  - 进行中显示「分析中…」，完成后卡片出现「查看报告」入口，报告页支持标题/列表/引用排版；
  - 同一机会重复分析需等前一次完成；失败（或服务重启导致中断）可点「重新分析」；
  - 报告存为 `data/reports/` 下的 `.md` 文件，头部带免责声明（数据来自模型训练知识，决策前请核实）。
- AI 分数只是建议：每个维度都可**随时拖动调整**，服务器即时重算总分与分档。
- 点「转正为目标」→ 一键升级，直接出现在目标页。
- AI 为可选功能：在仓库根 `.env` 配置 `WORKBENCH_AI_API_KEY` 等变量后生效（见第 8 节）；未配置时转正以 0 分创建，不阻塞流程。

### 5.4 目标

- 目标 = 承诺投入的方向，包含：标题、描述（为什么值得做）、里程碑列表（逗号或换行分隔）、进度。
- **进度**两种更新方式：
  - 手动拖进度滑块直接改（后写覆盖）；
  - 每晚复盘时按完成量自动 +（见 5.6）。
- 状态标签：`active`（进行中）/ `paused` / `done` / `abandoned`。
- 新建入口：页头「+ 新目标」。

### 5.5 任务

- 四个分桶：**今天 / 本周 / 未来 / 归档**（按 `scheduled_for` 排期自动分桶，归档=已完成）。
- 新建任务可挂靠目标（不挂 = 维护类）、可排期（日期）。
- 勾选即完成，进入归档桶；再点撤销。

### 5.6 复盘（时间线）

- 入口在首页「开始复盘」，每晚一次。
- 生成内容：当日完成清单 + 各目标进度变化。
- **进度规则（V0 简化）**：每个完成的"挂目标任务"让对应目标进度 **+10%，封顶 100%**。
- **幂等**：同一天同一范围只生成一份复盘，重复点击返回已有结果，不会重复加进度。
- 时间线按日期倒序，显示完成数摘要、正文、目标进度变化标签。

## 6. 个人 / 家庭范围

顶栏「个人 / 家庭」切换全局范围，影响今日、想法、机会、目标、任务的数据视图：

- **个人**：只有自己的数据。
- **家庭**：家庭共享数据（如共同目标、家务任务），标签会标注「家庭」。
- 复盘按范围独立生成（同一天可以既有个人复盘也有家庭复盘）。
- 选择会记住（localStorage），下次打开保持。

## 7. 数据存储与备份

- **一切皆 Markdown 文件**：每个实体一个 `.md`，元数据在 YAML frontmatter，正文在正文区。
- 目录结构（仓库根 `data/`）：

```
data/
├── users/          # 账号（含 bcrypt 密码哈希）
├── ideas/          # 想法
├── opportunities/  # 机会
├── goals/          # 目标
├── tasks/          # 任务
├── reports/        # 领域分析报告
└── reviews/        # 每日复盘
```

- 文件名即 ID：`20260822-idea-1a2b3c.md`（日期 + 类型 + 随机后缀）。
- **备份 = 备份 `data/` 目录**。建议把整个仓库纳入 git，任何误操作都能从历史恢复。
- 无数据库、无缓存：每次请求直接读写文件，个人规模（千级条目）完全够用。

## 8. 配置参考（环境变量）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 后端端口 |
| `WORKBENCH_DATA_DIR` | `<仓库根>/data` | 数据目录（e2e 测试用独立临时目录就是靠它） |
| `WORKBENCH_JWT_SECRET` | `dev-secret-change-me` | JWT 签名密钥，**对外部署务必改掉** |
| `WORKBENCH_API` | `http://localhost:3000` | 前端 dev 代理目标（web/vite.config.ts） |
| `WORKBENCH_AI_API_KEY` | 空 | AI 初评密钥（Anthropic 兼容接口）；未配置则 AI 功能返回 503 提示 |
| `WORKBENCH_AI_BASE_URL` | `https://open.bigmodel.cn/api/anthropic` | AI 接口地址 |
| `WORKBENCH_AI_MODEL` | `glm-5.3` | AI 模型名 |

> 开发时把配置写进仓库根 `.env`（参考 `.env.example`，已被 .gitignore 忽略），服务启动自动加载。

## 10. 常见问题

**Q：密码忘了、也没有家人账号能互证？**
用管理端 CLI：`npm run reset-password -w server -- --username <账号> --password <新密码>`。

**Q：AI 初评的分数不靠谱怎么办？**
初评只是起点：拖动滑块改成你自己的判断即可（分数和分档即时重算）。AI 未配置时转正以 0 分创建，可随时在机会页点「AI 初评」补打。

**Q：复盘点了两次，目标进度会加两次吗？**
不会。复盘按「日期 + 范围」幂等，第二次点击直接返回已生成的结果。

**Q：任务怎么才算"今天"？**
排期日期（`scheduled_for`）等于今天的任务进入「今天」桶；不排期的任务在「未来」桶，可随时改排期。

**Q：想换一台电脑用？**
整个系统是本地文件：拷贝仓库 + `data/` 目录，`npm install && npm run dev` 即可原样恢复。配合 git 远程仓库最佳。

**Q：数据会丢吗？**
文件直写无事务，极端情况（如写一半断电）单文件可能损坏；用 git 管理仓库即可兜底恢复。
