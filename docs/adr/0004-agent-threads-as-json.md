# ADR-0004：Agent 会话以 JSON 文件存储（对「一切皆 Markdown」的定向豁免）

## 背景

ADR-0001 规定每个实体 = 一个带 frontmatter 的 `.md` 文件。V1.1 新增 AI Agent 板块，会话记录除正文外还包含流式中间态、工具调用与审批状态、思考过程、token 用量等结构化字段。

## 决策

**Agent 会话存为 `data/agent/threads/<日期>-<后缀>.json`，每会话一文件。** 不造 markdown 转录语法去承载结构化消息流。

这一豁免限定于 Agent 会话；知识库、想法、机会、目标等其他一切实体仍然严格遵守 ADR-0001。

## 理由

ADR-0001 的本质是「无数据库、纯文本文件、git 即版本控制、零迁移成本」，JSON 文件四条全中，并未背叛该原则；牺牲的只是"肉眼直读"，而会话的重读载体是沉淀后的知识文件，不是原始消息流。若强行 md 化需自造转录标记语法，解析脆弱且丢中间态。

## 后果

- assistant-ui threadListAdapter 与 token 统计后台直接读写该文件，零转换
- 会话文件可进 git diff/回滚（含敏感对话内容，`data/` 默认不被仓库跟踪，沿用现状）
