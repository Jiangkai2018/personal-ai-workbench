SECTION 01

研究方法与数据管线

调研采用「广撒网关键词 + 搜索 API 分页」策略，保证每个关键词取满 5–8 页（每页 20 条），再以帖子 ID 全局去重。相比只搜「做抖音」，这能捕捉到用「起号」「恰饭」「播放量」等黑话讨论同一话题的发言。

  1. 抓取18 关键词 × 5–8 页搜索 API，共 1,738 条
  2. 去重按帖子 ID 合并，1,599 条（415 条被多个关键词命中）
  3. 过滤正文须真实涉及内容创作，剔除「恰饭=吃饭」等语义噪声，剩 1,184 条
  4. 打标26 类主题规则标签（平台/变现/痛点/做法/身份/结果）可多重命中
  5. 精读按互动量排序，精读 Top120 + 2025–26 近期 Top100

SECTION 08

深度结论

「做抖音」作为话题已经过气，「做自媒体」作为生存策略正在巅峰

抖音提及率 22%→15%，且叙事主体从「素人博主」切换为「商家与服务商」；与此同时讨论重心全面转向「多平台组合 + 私域 + 产品」的全链路。抖音被重新定价为一台商业化机器——它依然赚钱，但不再是普通人的故事。

变现共识高度收敛：内容是获客前端，不是生意本身

「先想清楚卖什么、卖给谁，再选平台做内容」是高赞方法论的公共分母。广告被一致评为最差路径（「几十万粉不赚钱一大把」），带货与私域服务离钱最近。真正赚到大钱的样本都出现在「内容直接服务交易决策」的形态里（评测、种草、咨询）。
